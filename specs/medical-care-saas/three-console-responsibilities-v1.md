# 医养照护 SaaS 三端职责与平台运营能力边界

## 1. 核心划分

三端不是同一套功能的三个尺寸，而是三个不同责任主体的工作空间：

| 工作空间 | 主要使用人 | 核心问题 | 数据边界 |
| --- | --- | --- | --- |
| 工作人员小程序 | 护理、服务及上门人员 | 今天做什么、现在填什么、还缺什么 | 只看本人有权执行的任务和必要老人信息 |
| 机构管理后台 | 门店负责人、部门主管、审核及运营人员 | 本机构如何建档、派单、审核、归档和核销 | 管理本机构业务正文，按部门和角色控制 |
| 平台运营后台 | SaaS 平台运营、客户成功、技术运维及安全人员 | 哪些机构需要处理、平台是否稳定、收入与成本是否健康 | 默认只看租户元数据和聚合指标，敏感正文必须临时授权 |

本地 API 不构成第四个工作台。它负责统一身份、租户隔离、状态校验、文件权限和审计，任何客户端都不能绕开它直接决定业务状态。

## 2. 工作人员小程序

### 应当具备

- 本人任务、待修改任务和工作身份；
- 服务对象的必要脱敏信息、任务时间、地址提示和联系规则；
- 服务项目、负责人、协作人员和阶段进度；
- 服务前、中、后三阶段动态表单、位置状态及影像上传；
- 草稿保存、缺项定位、整单提交、退回修改和只读历史；
- 断线、租户停用、无权限和上传失败后的恢复入口。

### 不应具备

- 老人档案的自由检索和批量导出；
- 服务项目、模板、权限或审核规则配置；
- 修改他人的履约正文；
- 平台费用、租户容量、全机构统计或平台审计。

## 3. 机构管理后台

### 业务责任

- 管理老人、联系人、授权、护理信息和服务关系；
- 管理员工、部门、角色和资质；
- 配置服务目录和员工填写表单；
- 建立持续服务关系或直接派发单次任务；
- 审核、按阶段和字段退回、跟踪异常并自动归档；
- 管理合同、消费券核销、宣传素材、食品追溯和机构导出；
- 创建临时支持授权，并查看本机构的套餐、容量和到期风险。

### 权限边界

- 审核人员不能改写员工履约正文；
- 老人档案不重复录入任务执行结果；
- 原始履约影像与宣传素材权限分离；
- 机构只能处理本租户数据；
- 平台套餐和费用可以查看，但不能自行修改计费结果。

## 4. 平台运营后台

平台端应围绕五个中心建设，而不是复制机构后台。

### 4.1 租户与客户成功

- 机构创建、试用、启用、只读、停用、续期和容量调整；
- 机构联系人、合同主体、实施负责人和服务状态；
- 接入进度：账号、部门、员工、首位老人、首个模板、首条任务；
- 近 7 日和 30 日活跃情况、任务使用量、审核退回率等聚合指标；
- 培训、问题单、回访、续约风险和客户健康状态。

平台只显示聚合结果，不因为“客户成功”而开放老人或履约正文。

### 4.2 商业运营

- 套餐、订阅周期、软件服务合同和续费记录；
- 应收、实收、欠费、退款、优惠和手工调整记录；
- 发票申请、开票状态和票据编号；
- 月度经常性收入、续费率、客单价和逾期金额。

首版采用手工账务台账，不冒充在线支付或正式财务系统。真实收款、电子发票和会计凭证在取得供应商与公司主体后接入。

### 4.3 资源与成本

- 每机构原始影像、证据副本、合同及导出文件的存储用量；
- 上传量、下载量、外网流量、接口调用量和失败数量；
- 数据库及备份体积、文件增长趋势和容量预测；
- 按已配置云单价计算的预估成本，并明确标记为估算；
- 套餐额度、超额量及需要扩容的机构。

CPU、内存、磁盘、网络和数据库连接数属于运行资源指标。生产阶段应读取腾讯云或实际供应商监控，本地原型只展示本机可验证值，不能生成虚假曲线。

### 4.4 稳定性、安全与合规

- API 可用性、启动时间、请求量、错误率和慢请求；
- 上传失败、异步任务积压、备份结果和恢复演练记录；
- 高权限登录、批量下载、档案导出、授权访问和异常失败；
- 临时支持授权的原因、范围、剩余时间、下载权和使用轨迹；
- 保存期限、删除队列、法律保全和机构退出导出状态；
- 民政通、长护险、电签、短信和云存储等外部接口的真实接入状态。

### 4.5 产品与平台配置

- 平台运营账号、角色和二次验证策略；
- 套餐能力、机构级功能开关和灰度范围；
- 版本发布、数据库迁移、公告和维护窗口；
- 平台级服务目录推荐项、资质规则和地区规则版本；
- 审计词典、告警阈值和通知接收人。

## 5. 当前版本优先级

### 当前原型应补齐

1. 可验证的本地运行指标：API 启动时间、进程内存、SQLite 大小、测试上传目录大小；
2. 各租户容量、有效期、状态、账号数量和近期开通情况；
3. 手工订阅与费用台账，不接在线支付；
4. 支持授权、关键审计、备份状态和未接入服务；
5. 机构接入进度和需要平台处理的待办。

### 接入第二家真实机构前补齐

1. 套餐版本、续费规则、超额计费和发票流程；
2. 客户成功记录、问题单和实施进度；
3. 机构级功能开关、平台运营角色和通知；
4. 分租户资源成本与容量预测。

### 生产上云后补齐

1. 腾讯云监控、日志、告警、对象存储和备份实际指标；
2. 错误率、延迟、任务队列、网络流量和数据库运行指标；
3. 正式支付、开票、短信、电签及监管接口状态；
4. 安全事件、恢复演练、合规删除和数据出口控制。

## 6. 明确不进入平台常规视图的内容

- 老人姓名、身份证、健康详情和家庭地址；
- 合同正文、服务阶段正文和原始照片视频；
- 机构员工个人绩效明细；
- 平台人员直接修改任务、审核结果或核销材料；
- 没有来源的“服务器健康分”“机构风险分”等黑箱评分。

出现投诉、争议或技术支持需要时，由机构针对具体对象创建限时授权；授权到期或撤回后，平台受控入口立即关闭，访问过程完整审计。
