# 平台机构治理第一版需求

## 范围

本轮完成机构资质提交、平台审核、服务权限门禁、机构档案、演示套餐价格和外部能力生命周期展示。老人、合同正文及原始履约影像不进入平台机构档案。

## 用户故事

1. 机构管理员可以上传资质材料并查看审核进度，但不能自行改变审核结论。
2. 平台运营人员可以查看机构资质元数据、作出通过或退回决定，并据此开放对应专业服务。
3. 平台运营人员可以为每家机构建立并维护基础档案，而不只是修改租户运行状态。
4. 平台运营人员可以按统一的演示套餐为机构配置月度订阅。
5. 平台运营人员可以区分“规划中、待配置、已接入、维护中、异常”等系统能力阶段。

## 验收条件

1. 当机构查看资质中心时，系统应只提供上传、提交审核及查看状态操作，不提供审核状态选择器。
2. 当机构尚未上传材料时，系统应显示“未上传”；上传演示材料后应显示“已上传，待提交”；提交后应显示“待平台审核”。
3. 当平台审核资质时，系统应记录审核人、审核时间、结论及退回原因，并写入审计日志。
4. 当所需资质未审核通过或已过期时，系统应禁止机构启用对应专业服务或发布含该服务的受限表单。
5. 当资质审核通过时，系统应允许机构启用对应服务；平台撤销或资质到期后，新业务应立即受限，历史记录保持可读。
6. 当平台新建或编辑机构时，系统应保存机构类型、统一社会信用代码、负责人、联系人、电话、行政区划、地址、接入阶段、服务范围和备注。
7. 当平台查看机构列表和详情时，系统不得返回老人、合同正文或原始影像。
8. 套餐月价应为免费演示版 0 元、单店入门版 128 元、单店标准版 328 元、机构专业版 648 元。
9. 当外部能力尚未接入时，系统应显示“规划中”或“待配置”等生命周期状态，不得伪造成功接入。
10. 所有禁用按钮和表单控件文字应满足可读对比度，不得出现白字落在白色或透明背景上的情况。

## 非目标

- 不上传真实资质文件，不接生产对象存储。
- 不实现真实收费、支付或开票。
- 不接入正式电子签章、民政通、长护险、短信或云存储。
